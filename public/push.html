Push ke GitHub

Kirim Website Xyverse dan Dashboard Admin ke repositori masing-masing

Kredensial GitHub

Dipakai untuk kedua proyek. Tidak disimpan di server dan tidak ditulis ke .git/config.

Buat di GitHub → Settings → Developer settings → Personal access tokens. Token klasik butuh cakupan repo; token fine-grained butuh Contents: Read and write pada kedua repositori. Token hilang saat halaman ditutup — hanya pemilik repo yang diingat di browser ini.

Menjalankan kedua kartu berurutan memakai pesan commit masing-masing.
Repositori harus sudah dibuat di GitHub (boleh kosong, tanpa README). Halaman ini hanya berfungsi saat API admin berjalan dan kamu sudah masuk. Berkas .env tidak pernah ikut ter-push — sudah masuk .gitignore.
